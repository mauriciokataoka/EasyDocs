# EasyDocs

Scaffold mínimo de documentação orientada a agente (IA). Fornece `AGENTS.md` e `SCAFFOLD.md` para iniciar qualquer projeto com docs canônicas, ADRs e versionamento — sem dependências.

## O que é
Um repositório-template: copie a pasta `seed/` inteira para a raiz do projeto novo, renomeie com o nome do projeto, e execute `AGENTS.md`. O agente inicializa `README`, `docs/` (PRD, ARCHITECTURE, DESIGN, ROADMAP, CHANGELOG, adr/), configurações VSCode e versiona com git.

## Documentação do agente
As docs canônicas vivem em [`docs/`](docs/):
- [[PRD]] — identidade e problema
- [[ARCHITECTURE]] — estrutura técnica
- [[DESIGN]] — UX/UI
- [[ROADMAP]] — afazeres
- [[CHANGELOG]] — versões

Veja `docs/adr/INDEX.md` para decisões (ADRs).
