Como criar e manter ADRs. O índice e os status ficam só em [INDEX.md](INDEX.md).

# ADRs — EasyDocs

- Cada decisão significativa vira `NNNN-titulo-kebab.md` a partir de [0000-template.md](0000-template.md) (Nygard + Alternativas).
- Indexe em [INDEX.md](INDEX.md) com Nº, título, domínio e status (`proposed | accepted | superseded | deprecated`).
- Decisão substituída: status `superseded` apontando a substituta; o conteúdo antigo não é apagado.
