# Notas de campo

Cada nota (`AAAA-MM-DD-assunto.md`) registra ambiente, comandos, resultados, limitações e hipóteses. Não é decisão (ADR) nem arquivo morto (`history/`). Não reescreva uma nota para parecer decisão definitiva: correções entram em nova nota. Quando uma nota gerar decisão, crie ADR; quando gerar trabalho, crie item no [ROADMAP](../ROADMAP.md).
